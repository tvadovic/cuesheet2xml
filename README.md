# Cuesheet → XML

Webová aplikácia, ktorá z playlistu (Excel .xlsx, CSV alebo tabuľka skopírovaná z Google Sheets) vyrobí XML pre FM playlisty.

**Otvoriť:** https://tvadovic.github.io/cuesheet2xml/

1. Nahraj .xlsx alebo vlož skopírované bunky aj s hlavičkou (Artist, Track Name, Autori hudby, Vydavatel, Rok, SK_IsMusic, SK_IsText, SKAuthor).
2. Zadaj celkový čas mixu (mm:ss alebo h:mm:ss).
3. Stiahni XML.

Čas sa delí rovnomerne medzi skladby, alebo – ak nahráš audio mixu – sa skutočné začiatky skladieb nájdu podľa zmien zvuku (dajú sa ručne opraviť a vypočuť tlačidlom ▶). Všetko beží v prehliadači, nič sa nikam neposiela.
